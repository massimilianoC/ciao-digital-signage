# Communication Handoff Brief

Use this document as the source package for an agent or team building a public project presentation website.

## Objective

Create a small presentation site that clearly separates:

- Community/non-commercial adoption path.
- Commercial contact path.

## Core Messaging

Product name:

- Ciao Digital Signage
Subtitle:
- Digital Signage

Positioning:

- Web-first digital signage platform.
- Multi-tenant CMS + browser-based player.
- Connector model for embedded webapps.

## Audience Segments

1. Community users
   - Makers, schools, non-profits, open collaboration users.
2. Small organizations
   - Teams evaluating lightweight digital signage.
3. Commercial prospects
   - Organizations needing support, customization, or licensing.

## Required Site Sections

1. Hero
   - Name, subtitle, value proposition, primary call-to-action.
2. Features
   - Key platform capabilities from README.
3. Community path
   - How to contribute, discuss, and open issues.
4. Licensing path
   - Non-commercial summary + commercial contact.
5. Roadmap and milestones
   - Public roadmap and release maturity.
6. Technical trust
   - Security policy, release process, changelog.

## Tone of Voice

- Clear, practical, and transparent.
- No exaggerated claims.
- Distinguish explicitly between community use and commercial engagement.

## Calls To Action

Community CTA examples:

- "Join the community"
- "Open an issue"
- "Contribute"

Commercial CTA examples:

- "Request commercial license"
- "Contact for partnership"
- "Enterprise support"

Commercial contact email placeholder:

- <licensing@ciao.example>

## Do Not Include

- Internal/private runbooks.
- Infrastructure secrets or sensitive deployment details.
- Non-public planning artifacts.
